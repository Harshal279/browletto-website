# Browletto demo website

Responsive static demo site for Browletto.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — menu filtering and demo interactions

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example `browletto-website`).
2. Upload the contents of this folder, keeping `index.html` at the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, branch `main`, folder `/(root)`, and Save.
5. Wait for the published URL to appear.

## Before using it for the real business
Update the demo prices, address, social links, product details, and contact details. The dessert photos use remote Unsplash URLs, and Google Fonts are loaded online. This is a front-end demo only; it does not process real orders or payments.
